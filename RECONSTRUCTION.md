# Reconstruction note

This repository was rebuilt after the original Android development phone was reset. It is not claimed to be byte-for-byte identical to the deleted tree.

The reconstruction uses complete source fragments preserved in the development conversation, exact known USB topology, exact Mixxx-derived HID offsets/masks, the last-known Termux build workflow, and the last-known live hardware logs.

Before large architectural changes, validate this reconstructed baseline on the physical S4 MK2 and commit a fresh hardware-verified checkpoint.
